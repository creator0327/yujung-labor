## 데이터 모델 (RESTful Table API)

### consultations 테이블 (12개 필드)
| 필드명 | 타입 | 설명 | 옵션 |
|--------|------|------|------|
| `id` | text | 고유 ID (자동) | — |
| `name` | text | 신청자 이름 | — |
| `phone` | text | 연락처 | — |
| `email` | text | 이메일 | — |
| `company` | text | 회사/기관명 | — |
| `applicant_type` | text | 신청인 구분 | 사업주, 근로자, 기타 |
| `category` | text | 상담 분야 | 노동분쟁, 직장내괴롭힘, 산업재해, 임금체계컨설팅, 취업규칙/인사규정, 중대재해예방, 4대보험/보험사무, 노무관리컨설팅, 기타 |
| `message` | rich_text | 상담 내용 | — |
| `prefer_method` | text | 선호 상담 방법 | 전화, 방문, 이메일, 상관없음 |
| `status` | text | 처리 상태 | 접수, 검토중, 상담완료, 보류 |
| `memo` | text | 내부 메모 (관리자용) | — |
| `created_at` | datetime | 신청일시 (자동) | — |

### 관리자 페이지 기능
- **로그인**: 세션 기반 간단 인증 (아이디/비밀번호)
- **목록 조회**: 전체 상담 목록, 페이지네이션, 정렬
- **검색/필터**: 이름·전화번호·회사명 텍스트 검색, 상태·분야·신청인 구분 필터
- **상세 보기**: 모달 팝업으로 전체 상담 내용 확인
- **상태 변경**: 접수 → 검토중 → 상담완료 / 보류 변경 및 저장
- **내부 메모**: 관리자 전용 메모 입력/수정
- **삭제**: 확인 대화상자 후 데이터 삭제
- **Excel 내보내기**: 현재 필터 조건의 데이터를 CSV 파일로 다운로드 (한글 BOM 처리)
